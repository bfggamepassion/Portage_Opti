# Prompt image : format Amstrad CPC mode 0

À utiliser dans un générateur d'images (ChatGPT ou autre) pour produire des planches de sprites, décors ou
écrans titres au style CPC mode 0. L'image obtenue se convertit ensuite en données CPC avec les outils des
kits (`cpcgfx.py`, `cpcpal.py`) : palette réduite aux 27 couleurs, 16 au plus, pixels 2:1.

```text
Pixel art graphics in strict Amstrad CPC Mode 0 style.

Visual Specs & Pixel Constraints:
- Resolution & Aspect Ratio: Low-resolution pixel art featuring ultra-wide rectangular pixels with a 2:1 horizontal aspect ratio (pixels are twice as wide as they are high).
- Color Palette Constraints: Strict maximum of 16 solid colors displayed simultaneously on screen. No gradient blending, no antialiasing, no semi-transparent pixels, no modern lighting or blur.
- Color Palette Options (select strictly from the classic 27-color RGB CPC palette): Black, Blue, Bright Blue, Red, Magenta, Mauve, Bright Red, Purple, Bright Magenta, Green, Cyan, Sky Blue, Yellow, White, Pastel Blue, Lime Green, Bright Cyan, Pastel Green, Bright Green, Sea Green, Bright Yellow, Pastel Yellow, Pink, Pastel Magenta, Orange, Pastel Pink.
- Shading Technique: Use retro 16-bit/8-bit pixel dithering patterns (checkerboard pixel patterns) to simulate lighting and texture transitions.
- Edges: Extremely sharp, blocky, aliased pixel edges. Clean, crisp retro video game aesthetic typical of 1980s 8-bit European microcomputers.
800x1000 pixels
```
